# ResearchFlow-Bench（预备）

这里保存统一评估集的公开模板，不保存论文正文或私人研究资料。

## 论文登记

使用 `papers.template.csv` 登记合法来源、版本、SHA-256、许可证和人工审核状态。PDF 文件应留在项目外的受控目录，评估记录只保存路径映射或脱敏 ID。

## 统一任务

`questions.yaml` 定义 B01–B12 的输入问题和所需证据。每个候选项目必须使用相同论文、问题、模型配置和权限；项目未支持的能力标记为 `not_supported`，不能由外部工具代做后计入该项目成绩。

## 门禁

完成 10 篇论文、人工参考答案和第一轮盲测前，不输出准确率、Recall@10 或“最佳项目”结论。
